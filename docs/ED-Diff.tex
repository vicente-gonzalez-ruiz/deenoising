a zero-shot denoising algorithm based on diffusion models. The core concept of ED-Diff is to utilize diffusion models to learn the prior knowledge of clean fluorescence microscopy images and generate corresponding denoised images by guiding the sampling process with noisy images. To achieve this, ED-Diff integrates the iterative solution of a MAP model with the sampling process and employs a transformation module with an encoder-decoder structure to handle complex real-world noise. The model is pre-trained on a high-SNR dataset, and during inference, only a lightweight network needs to be trained additionally.
