\section{Supervised learning}

Supervised (or paired) denoisers require one o more clean images
  and their respective noisy instances to learn, by comparison, what
  is noise and what is the clean signal (a ground truth must
  exist). In other words, we must have one or more pairs
  $\{(\tilde{\bm{X}}_i,\bm{X}_i)\}_{i=0}^{N\in\mathbb{N}}$. Supervised
  denoisers are also classified as \gls{N2C} methods and
  distribution-based methods, because the model learns the statistical
  ``look'' of clean images. A supervised model $\Theta$ learns
  \begin{equation}
    \Theta(\tilde{\bm{X}}) \approx \bm{X}.
  \end{equation}
  Examples of image denoisers trained in a supervised way are DnCNN,
  FFDNet, and Restormer.

\section{Unsupervised learning}
Unsupervised (unpaired) denoising does not require paired
  examples $(\tilde{\bm{X}},\bm{X})$, although we need a collection of
  noisy images (with the type of noise we want to remove) and a
  collection of clean images (the content of the images could be any
  and different to the content of the noisy ones). So, we need a set
  $\{\tilde{\bm{X}}_i\}_{i=0}^{N\in\mathbb{N}}$ with noisy images, and
  an independent set $\{\bm{Y}_i\}_{i=0}^{M\in\mathbb{N}}$ with clean
  images. GAN-based denoiser can be classified as unsupervised. GANs
  are unsupervised.

\subsection{Zero-shot}
\textbf{``Zero-Shot'' denoisers}: when you have only one instance
$\tilde{\bm{X}}$ and during the training
$model(\tilde{\bm{X}})=\tilde{\bm{X}}$, you stop when you consider
that the model is learning the noise (natural image structure emerges
before noise memorization). For example, \gls{DIP}, based on the fact
that autoencoders with skip connections (U-Nets, although this is true
also for all denoising \gls{DL}-based techniques) learn first those
information in an image that is not noise, an U-Net is trained to map
a random image $\bm{N}$ to $\tilde{\bm{X}}$. In an optimal point of
the training process, the U-Net will generate a
$\hat{\bm{X}}\approx\bm{X}$.

\section{Reinforcement learning}
\gls{RL} allows an agent to learn iteratively, which sequence of
choices/hyperparameters should be taken/used to optimize some
process. In each step, usually implemeted as a Markov
process\footnote{Where the agent only remembers the previous state.},
the agent explores a set of alternatives, learning from the previous
decissions. In the case of image denoising, the agent should learn
(possiblely using a brute-force search, specially at the begining of
the learning process) the best denoising parameters (for example, the
optimal length of a Gaussign filter depending on the iteration of the
local content of the image).

\section{Training of a regression model for denoising} % Noise2Noise: Learning Image Restoration without Clean Data https://arxiv.org/pdf/1803.04189
A regression model, e.g., a \gls{CNN} can be trained using a number of pairs $(\hat{{\mathbf x}}_i, {\mathbf y}_i)$ of corrupted inputs $\hat{{\mathbf x}}_i$ and clean targets ${\mathbf y}_i$, and minimizing the empirical risk
\begin{equation}
  \underset{\theta}{\operatorname{arg\,min}} \, \sum_i L \big(f_\theta(\hat{\mathbf x}_i), {\mathbf y}_i\big)
  \label{eq:supervised_learning}
\end{equation}
where $f_\theta$ is a parametric family of mappings (e.g., CNNs) under the loss function $L$.
